# 42ponzi documentation

42ponzi (`PONZ`) is an educational ERC-20 token on the Ethereum Sepolia testnet. A 2-of-3 multisig wallet owns it, so no single key can mint tokens.

**PONZ has no monetary value.** It exists only on a testnet, as a school project.
